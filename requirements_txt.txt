# 🎰 Streamlit 로또 번호 생성기 (Lotto Number Generator)

Streamlit을 활용하여 실제 로또 공 색상 스타일을 반영한 6자리 중복 없는 로또 번호 생성기 웹 애플리케이션입니다.

## 📌 주요 기능

* **로또 번호 자동 생성**: 1부터 45 사이의 중복 없는 random 번호 6개를 추출하여 오름차순으로 정렬합니다.
* **최대 5세트 누적**: 버튼을 누를 때마다 세트가 추가되며, 최대 5개 세트까지 저장하여 한눈에 비교할 수 있습니다.
* **실제 로또 공 색상 적용**:
  * 🟡 **1 ~ 10번**: 노란색
  * 🔵 **11 ~ 20번**: 파란색
  * 🔴 **21 ~ 30번**: 빨간색
  * ⚪ **31 ~ 40번**: 회색
  * 🟢 **41 ~ 45번**: 초록색
* **초기화 기능**: 번호 초기화 버튼을 눌러 목록을 비우고 다시 시작할 수 있습니다.

## 🛠️ 실행 방법

### 1. 의존성 패키지 설치

```bash
pip install -r requirements.txt
```

### 2. Streamlit 앱 실행

```bash
streamlit run app.py
```

*(실행하려는 파이썬 코드 파일명이 `app.py` 기준입니다.)*
